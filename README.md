# pomo
A physical timer for the ESP32 - can be a pomodoro as well a normal countdown/stopwatch. It is modeled after the [ones on Amazon](https://www.amazon.com/Rotating-Pomodoro-Minutes-Productivity-Vibration/dp/B0D7JG4VLD).

## Planned Features
- Controlled by gyroscope (similar)
- Web Panel (for changing side minute values)
- Physical enclosure + schematics (requires CAD and 3D Printing)
